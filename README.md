# Tianyu Yang | University of Notre Dame

Source code for [Tianyu Yang's academic homepage](https://tianyu-yang-anna.github.io/).

I am a Computer Science PhD student at the University of Notre Dame, advised by
Professor Xiangliang Zhang. My research focuses on post-training LLMs and MLLMs
to build agents that perceive, reason, and act.

## Website Content

- `_pages/about.md`: biography, news, publications, and academic service.
- `_config.yml`: site URL, author information, and search metadata.
- `images/`: profile photo, logos, and publication figures.

## Debug Locally

1. Clone your REPO to local using `git clone`.
1. Install Jekyll building environment, including `Ruby`, `RubyGems`, `GCC` and `Make` following [the installation guide](https://jekyllrb.com/docs/installation/#requirements).
1. Run `bash run_server.sh` to start Jekyll livereload server.
1. Open http://127.0.0.1:4000 in your browser.
1. If you change the source code of the website, the livereload server will automatically refresh.
1. When you finish the modification of your homepage, `commit` your changings and `push` to your remote REPO using `git` command.
